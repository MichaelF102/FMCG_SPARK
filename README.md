## 📖 1. Executive Summary & Research Question

Fast-Moving Consumer Goods (FMCG) enterprise retail requires highly scalable and accurate daily point-of-sale demand forecasting across thousands of SKUs and retail channels.

### Central Research Question:
> *"How does distributed PySpark machine learning compare with single-node machine learning in terms of execution time, resource utilization, predictive accuracy, and scalability as FMCG dataset size increases from 1 million to 3 million and 5 million records?"*

### Key Experimental Controls:
- **Continuous Regression Target**: `units_sold` (Daily item units sold).
- **Target Leakage Prohibition**: Mathematically derived variables (`gross_sales = units_sold × list_price` and `net_sales = gross_sales - discount`) are strictly excluded prior to feature engineering.
- **Fair Ground Truth**: All frameworks train and evaluate on identical **Gold Parquet** splits generated by a shared PySpark Medallion Lakehouse pipeline.

## 🏆 3. Multi-Scale Benchmark Results (1M, 3M, 5M Records)

### Master Machine Learning Performance Summary

| Scale | Model | Single-Node Time (s) | Distributed Time (s) | Distributed Speedup | RMSE | MAE | $R^2$ Variance |
|:---|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| **1M** | **Random Forest** | 66.70s | 17.38s | **3.84x** 🚀 | 13.91 | 9.94 | 0.8609 |
| **1M** | **LightGBM** | 4.86s | 6.27s | **0.78x** | 13.82 | 9.87 | 0.8628 |
| **1M** | **XGBoost** | 49.64s | 4.81s | **10.32x** 🚀 | 13.20 | 9.30 | 0.8748 |
| **1M** | **CatBoost** | 4.33s | 5.21s | **0.83x** | 13.78 | 9.84 | 0.8635 |
| **3M** | **Random Forest** | 269.10s | 66.70s | **4.04x** 🚀 | 13.89 | 9.92 | 0.8614 |
| **3M** | **LightGBM** | 14.50s | 17.80s | **0.81x** | 13.79 | 9.85 | 0.8633 |
| **3M** | **XGBoost** | 62.40s | 16.98s | **3.68x** 🚀 | 13.18 | 9.28 | 0.8752 |
| **3M** | **CatBoost** | 13.20s | 11.45s | **1.15x** 🚀 | 13.75 | 9.81 | 0.8641 |
| **5M** | **Random Forest** | 456.10s | 70.20s | **6.50x** 🚀 | 13.88 | 9.91 | 0.8615 |
| **5M** | **LightGBM** | 24.80s | 28.60s | **0.87x** | 13.78 | 9.84 | 0.8635 |
| **5M** | **XGBoost** | 109.71s | 16.98s | **6.46x** 🚀 | 13.14 | 9.26 | **0.8760** |
| **5M** | **CatBoost** | 32.70s | 15.64s | **2.09x** 🚀 | 13.74 | 9.80 | 0.8643 |

### Key Benchmark Takeaways:
1. **The Parallel Scaling Crossover Point**: Single-node C++ libraries (LightGBM/CatBoost) are faster on smaller datasets ($<1\text{M}$ rows) due to zero IPC socket overhead. As data scales to $3\text{M}-5\text{M}$ rows, single-machine CPU/RAM ceilings manifest, enabling PySpark cluster distribution to achieve major speedups (**6.50x on Random Forest**, **6.46x on XGBoost**).
2. **Predictive Invariance**: Model accuracy ($R^2 \approx 0.86-0.88$) is invariant across single-node and distributed execution. The primary value of PySpark is **computational speedup and memory headroom**, not algorithm accuracy.
3. **Resource Telemetry**: Single-node hits a **90.0% host RAM ceiling** on 5M rows, while the PySpark cluster balances memory at **72.6%** across 3 worker containers with up to **185.3 MB/s Disk I/O**.

## 🚀 5. Quickstart & Reproduction Guide

### Prerequisites
- Python 3.10+ (Python 3.12 recommended)
- Java 11 or 17 (for Apache Spark)
- Docker & Docker Compose (optional for cluster containerization)

### Step 1: Clone Repository & Set Up Virtual Environment
```bash
git clone https://github.com/your-username/FMCG_Spark.git
cd FMCG_Spark

python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Step 2: Run End-to-End Automated Pipeline
Generate synthetic data, run the Medallion pipeline, execute single-node & distributed benchmarks across 1M, 3M, and 5M datasets, and launch the dashboard:
```bash
chmod +x run_all.sh
./run_all.sh
```

### Step 3: Run the Interactive Streamlit Platform
```bash
streamlit run dashboard/Overview.py
```
Open **`http://localhost:8501`** in your browser.

## 🐳 6. Docker Spark Cluster Setup

To spin up the isolated 1-Master + 3-Worker Spark standalone cluster:
```bash
docker-compose up -d
```
- **Spark Master UI**: `http://localhost:8080`
- **Spark Master RPC**: `spark://localhost:7077`
- **Worker Nodes**: `spark-worker-1`, `spark-worker-2`, `spark-worker-3` (2 Cores, 2GB RAM each)
